# `workflows/`

Sequences - the **order** in which rules and patterns are applied for a recurring task. A workflow
composes rules and patterns (and sometimes other workflows) into a checklist.

## Index

| [api-implementation.md](api-implementation.md)                       | Adding a REST/gRPC endpoint                       |
| [repo-setup.md](repo-setup.md)                                       | Bootstrapping a new project                       |
| [dependency-addition.md](dependency-addition.md)                     | Adding a third-party dependency                   |
