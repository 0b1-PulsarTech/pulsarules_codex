---
id: l10n
name: Localization catalogue
---

Governs user-facing text: no literal string outside the message catalogue, and every message declares
all of its supported locales together in one declaration, so a locale can never be left partially
translated. Locales are a closed enum, never a bare string tag, at any decision point. Language- and
framework-neutral; reach for it whenever adding or editing any user-facing string, adding a message
key, or adding a new supported locale. See `l10n-svelte` for the SvelteKit server-resolution
mechanics (no i18n runtime or catalogue copy reaching the client bundle).

The rules below are the composed l10n rule.
